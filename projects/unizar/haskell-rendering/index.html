Dos formas de simular la luz

En este proyecto implementamos dos técnicas clásicas de síntesis de imagen: Path Tracing y Photon Mapping. La parte interesante fue llevarlas a Haskell y mantener una estructura suficientemente clara y eficiente para generar escenas con materiales difusos, especulares y refractivos.

El desarrollo ocupó unos seis meses. El programa genera imágenes PPM/BMP y cada una de las dos partes tiene su propia memoria, con la explicación matemática, los parámetros y los resultados completos.

Path Tracing

El path tracer aproxima la ecuación de render siguiendo caminos aleatorios y acumulando muestras por píxel. Incluimos muestreo de materiales y Next Event Estimation para tratar la luz directa y reducir el ruido en escenas complejas.

También construimos una BVH para acelerar las intersecciones. Así no hace falta recorrer toda la escena cada vez que se lanza un rayo. La implementación aprovecha además el paralelismo para repartir el cálculo del render.

Photon Mapping

El photon mapper añade una primera fase en la que se lanzan fotones desde las fuentes de luz y se guardan sus impactos con la energía asociada. Después se consulta esa información para estimar la energía que llega a cada zona de la escena.

Los fotones se organizan en un KD-tree, que permite buscar vecinos cercanos y calcular la densidad local. Esta técnica ayuda especialmente con fenómenos como las cáusticas, que pueden exigir muchas muestras con un path tracer puro. La solución combina ambas técnicas para resolver la iluminación directa e indirecta dentro del mismo renderizador.
