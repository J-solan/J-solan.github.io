Acercar la simulación al sensor real

La imagen transitoria estudia cómo se propaga la luz con una resolución temporal muy alta. Una de sus aplicaciones es la imagen NLOS: intentar recuperar información de un objeto que no vemos directamente a partir de la luz que rebota por la escena.

El hardware capaz de registrar estas señales es caro, delicado y difícil de calibrar. Por eso es habitual trabajar con simulaciones, aunque una simulación ideal no refleja por sí sola todo lo que ocurre al capturar la señal. En este TFG modelé el comportamiento de un sensor SPAD para reducir esa distancia entre la señal simulada y la que produciría un sistema físico.

El trabajo duró diez meses y obtuvo una nota de 9,0.

Del sensor al modelo

Primero estudié varias fuentes de ruido y limitaciones de los SPAD: la eficiencia de captura, la incertidumbre temporal, el crosstalk, el afterpulsing y otros eventos no ideales.

Después trasladé ese comportamiento a un modelo que puede aplicarse sobre histogramas temporales. La implementación se integra con Mitsuba 3 y mitransient, y usa Python y Dr.Jit para trabajar con el transporte de luz con componente temporal.

Cómo lo comprobé

Usé escenas con línea de visión directa y sin ella. La Cornell Box sirve como entorno controlado para observar la forma del pulso y la respuesta del sensor; la configuración NLOS-Z permite estudiar el transporte indirecto y la pérdida de señal cuando el objeto queda oculto.

El resultado permite comparar el histograma ideal con la señal degradada por el modelo de captura y analizar cómo ese ruido afecta a las reconstrucciones NLOS. Las figuras, las comparativas y el desarrollo completo están en la memoria del proyecto.
